# 동시 송출 화면 ‘헷갈려요’ 확인 기능

상태 — 구현 전 초안

## 화면 동작

| 사용자 | 버튼 표시 | 클릭 결과 |
| --- | --- | --- |
| 교수자 | ‘헷갈려요’ 번호에 마우스를 올리거나 키보드 초점을 맞추면 `확인` 버튼을 표시한다. 모바일에서는 번호를 탭한다. | 선택한 번호에 모인 태그를 확인 처리한다. 교수자 화면과 해당 학생 화면에서 처리된 태그를 제거한다. |
| 학생 | 본인 번호에 같은 방식으로 `확인` 버튼을 표시한다. | 자신의 태그만 확인 처리한다. 교수자 집계가 1건 줄고, 남은 태그가 없으면 번호가 사라진다. |

교수자 버튼 옆에는 “이 위치의 태그 3건”처럼 적용 범위를 표시한다. 마우스를 버튼으로 옮기는 동안 버튼을 유지하고, 키보드로 실행하거나 `Esc`로 닫을 수 있게 한다. 처리 중에는 버튼을 비활성화한다. 실패하면 태그를 유지하고 재시도 안내를 표시한다.

## 서버 처리와 동기화

- 화면에 표시되는 번호는 정렬에 따라 바뀔 수 있다. 서버는 수업·페이지·송출 버전과 태그 식별자로 처리 대상을 확인한다.
- 교수자는 선택한 위치에서 화면에 표시돼 있던 태그를 처리한다. 같은 위치에 새로 추가된 태그는 남긴다.
- 학생 요청은 서버에서 참여 권한과 태그 소유자를 확인한다. 학생 응답에는 다른 학생의 태그 식별자를 포함하지 않는다.
- 송출 버전이 바뀌었거나 수업이 종료됐거나 권한이 회수된 경우 처리하지 않는다. 이미 확인된 태그의 재요청은 집계를 다시 차감하지 않는다.
- 서버 저장 후 기존 송출 갱신 경로로 양쪽 화면에 반영한다. 태그만 바뀐 경우 교안 PDF를 다시 받거나 렌더링하지 않는다. 연결된 학생 질문과 선택 위치 기록은 보존한다.

## 완료 기준

| 시나리오 | 기대 결과 |
| --- | --- |
| 교수자가 3건이 모인 번호 하나를 확인 | 해당 3건만 사라진다. 다른 위치의 태그와 연결된 질문은 유지된다. |
| 학생 한 명이 자기 태그 확인 | 학생 화면에서 본인 태그가 사라지고 교수자 집계가 3건에서 2건으로 줄어든다. |
| 확인 직전에 새 태그 추가 | 기존 확인 대상만 처리되고 새 태그는 남는다. |
| 교수자·학생 동시 확인 또는 요청 재전송 | 태그 하나가 집계에서 한 번만 빠진다. |
| 페이지 전환·수업 종료·권한 회수 중 요청 도착 | 늦게 도착한 요청이 다른 페이지나 수업의 태그를 변경하지 않는다. |
| 마우스·키보드·모바일 사용 | 모두 버튼에 접근해 실행할 수 있다. 교안 문구 선택과 질문 연결 기능이 정상 동작한다. |
